# First full original-episode independent ASR and throughput experiment

**Status:** source-bound and credential-safe worker ready; no real two-model episode recognition has been run as of this document. [Fast episode factory target](FAST-EPISODE-FACTORY-THROUGHPUT.md) is <=30 minutes p95 for a complete first pass, **not** a measured guarantee. Existing S01E01 original AVI is SHA `5b607acc60fae6893aa76e5b02fc34900cbe68050eac486b31382dc91e504962`, 183,386,112 bytes, actual encoded 29.97fps, 1448.256s (source experiment [#40070932182](https://github.com/gamesbyian/general-purpose/actions/runs/40070932182)).

## One source, one decoded PCM, two genuinely different models

The trusted worker `tools/probe_s01e01_full_dual_asr.py` reads the exact owner source identity and SHA from existing pinned inventory, downloads the original AVI exactly once to ephemeral Actions disk and converts its whole audio to temporary 16kHz mono WAV **once**. The **same WAV SHA** is handed unchanged to:

1. `faster-whisper==1.2.1` **Whisper tiny.en**, CPU int8, beam1 for a speed-oriented first baseline, no initial vocabulary prompt and `condition_on_previous_text=false`.
2. `vosk==0.3.45` **Vosk small English 0.15**, architecturally distinct Kaldi acoustic/HMM+WFST recognizer, independent raw decoding from identical PCM, with word timestamps. Official Apache-2.0 lightweight 40MB English model `https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip`; archive SHA-256 locked to `30f26242c4eb449f948e42cb302dd7a686cb29a3423a8367f99ff41780942498`, as independently published with the identical model by mirrors. If original provider bytes disagree, the run must fail and investigate; **never turn off the SHA check to get a green result**.

Neither model receives the original SRT, the other model's transcript, or a dynamically added sitcom-character vocabulary. They run sequentially on the same runner so timings reflect independent CPU model inference without unpredictable two-model contention. Retain source transfer, PCM decode, model-download/unpack, each full-episode model inference, text consensus, and end-to-end source-runtime measurements (separately distinguish runner startup and pip installation). No source AVI/WAV, model weights, or voice embeddings enter artifacts or the repository.

Run two model word hypotheses through `tools/compare_independent_asr.py`, which recognizes distinct model families `whisper` versus `kaldi_hmm_wfst`, checks input SHA and unprompted inference provenance, makes affirmative ≥3-word independently machine-corroborated dialogue spans within 600ms and emits disagreements for review. Timestamp and text model hypotheses, not independently listened truth or named speakers. Rare comic words, audience laughter and vocabulary mismatch may substantially reduce Vosk consensus accuracy even if raw inference is fast.

A robust runner has a **27-minute maximum job duration**, though workflows are not true per-episode p95 until a full representative sample runs. If its inference exceeds available CPU budget, record a failure / choose smaller or accelerated model rather than scale an inefficient architecture to 193 episodes. The outputs are bounded to 15,000 words/model and a ≤5MB private 7-day JSON artifact; all media and downloads stay in one temporary directory that is wiped after analysis.
