# One-source episode fast factory integration benchmark

**Current stage:** combined source-once offline implementation, original full-episode integrated run pending; no production screenplay acceptance. Prior independent full source benchmarks: [dual ASR](research/s01e01-whole-dual-asr-benchmark-summary.json) measured 134.165s and [full source video](research/s01e01-full-video-throughput-summary.json) measured 55.239s, summing to 189.404s **across separate executions**. Source AVI encoded 30000/1001 fps. The proposed ≤30-minute p95 initial pass is not yet a measured fleet result.

`tools/profile_s01e01_one_source_factory.py` is the first **genuine one-AVI/one-PCM** orchestration: read the fixed original S01E01 AVI from the owner FTP once and SHA verify; decode one 16kHz PCM to temporary storage; independently free-decode entire audio with architecturally different Kaldi/Vosk and Whisper tiny.en CPU models, without source captions or other recognizer prompts; compute full original-video low-resolution FFmpeg frame-image change proposals; prioritize six genuine historical sampled video observation tasks and up to 26 **uniform coverage probes, not detected motion**; select ≤240 source frames within candidate-shot partitions; decode JPEGs from a single FFmpeg process and verify real original presentation timestamps. All original video/audio/JPEG/model weights reside in a single ephemeral trusted source directory. Only small numbers and provenance are uploaded privately.

The source worker measures a continuous **real monotonic clock from initiating original FTP transfer through the completion of both audio and picture analysis**. It also reports each stage separately and verifies that the sum is consistent with that clock. No overlapping GPU/CPU contention assumption is hidden: the real benchmark is serial; parallelization can be studied only after profiling. Existing detailed candidate ASR output is not duplicated in the integrated small artifact; instead the run reports model agreement spans/word counts, rejected timestamps and detailed reasons, image scores/selected frame counts and source-Presentation-PTS fidelity, bound to original source SHA, video rate and decoded PCM SHA.

**Go/no-go:** a single source combined pass finishing in substantially under the ≤30-minute target while retaining all measured source hashes and metadata, with no original media in artifacts. This does not prove *p95 across all 193 episodes*, edit detection precision, motion/physical-comedy recall, cast voice names, acting tone, original-audio word accuracy, or completed screenplays. Subsequent rigorous model and independent audiovisual reviewing remains necessary. Neither source SRT nor scene/cast editorial acceptance is automatically promoted.

After offline PR CI passes and merges, dispatch one source sample through branch `research/night-court-s01e01-one-source-trigger` with file `Night Court/research/trigger-s01e01-one-source-factory.txt`; trusted workflow checks out base `github.sha`, never PR head, and uses the already configured repository FTP secret only for original source retrieval. The trigger PR is closed without merging when the run's artifact is recorded.

**Conservative data contract:** camera cuts are candidate image changes, 26 extra triads are general coverage, independent model dialogue agreements are positive corroborated *machine hypotheses*, all speaker and performance identifications require separate evidence. 0/193 accepted original-series production screenplays.
