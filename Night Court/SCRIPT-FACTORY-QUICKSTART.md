# Night Court script factory: one click, one stable screenplay per episode

**Launch:** [Actions → Night Court script factory (one click)](https://github.com/GBIDEVELOPMENT/general-purpose/actions/workflows/night-court-script-factory.yml) → **Run workflow** on **main**. Enter `S05E05` (or any original-series `SXXEXX`, or `all` for all 193). Leave **Publish** enabled. There are no local setup steps or new secrets. A single Actions job produces the current screenplay, its immutable-source provenance, a P0/P1 review queue and a manifest. The workflow uploads a short-lived private artifact and, by default, commits the result to a *stable* private location.

**Local equivalent** (Python 3.11+, standard library, no packages, no media or API keys):

```sh
python 'Night Court/tools/script_factory.py' --episode S05E05
# Or produce all 193 original-series scripts:
python 'Night Court/tools/script_factory.py' --episode all
```

**Automatic research-backed refresh:** The same factory workflow seeds both source-checked canonical pilots **and any existing source-SHA-validated whole-episode contextual editorial overlays** (S05E05, S01E02, S01E03, S01E04 and S01E05) when deployed to private main. It refreshes those stable paths on the existing `night-court-canonical-published` event, factory code updates or newly committed episode speaker-review ledgers. No new manuscript version, external model run or media download is triggered. If a concurrent change advances main during the commit, the job fails safely and can be rerun. Other episodes remain an explicit one-click choice.

**Automatic agent/fan retrieval refresh:** The factory now reuses the **existing** private 193-episode `saved-private/pilot-current/private-fan-retrieval/` corpus, upgrading its script witnesses to the strongest SHA-checked stable screenplay whenever a current package exists. Initially that selects both canonical pilots and the source-context scripts **S01E02, S01E03, S01E04, S01E05 and S05E05**; all other 186 episodes retain their original complete source-only retrieval scaffolds until researched or explicitly generated. This corrects the previous mismatch in which fan agents were searching outdated anonymous S01E02/S01E03 scripts despite stronger published drafts. The exporter rejects source transcript SHA/version mismatches, modified screenplay bytes, invented S09 subtitle timing, and unsupported original-A/V acceptance. It never guesses performer identities from a cast list. Both normal main refreshes and manual **Publish** update the established retrieval manifest and chunks in the **same** Git commit as the screenplays, so no additional workflow or user step is necessary. Running without Publish leaves the committed retrieval untouched.

**Where output lives:** `Night Court/saved-private/script-factory-current/SXXEXX/`, exactly four files:
- `screenplay.md`: the strongest currently integrated screenplay. S01E01/S09E19 prefer canonical editor-completed provisional working manuscripts, then a fully source-AV-validated reviewed promotion if the existing one-pass acceptance ledger is complete. Every other episode gets all presently held dialogue in chronological order with exact source characters, cautious explicit source speaker labels and provisional passage divisions.
- `provenance.jsonl`: one record per canonical pilot reader block or one complete original caption cue for other episodes. Generic episode cues also carry **exact reversible Unicode character spans for typographically marked separate voices**, with stable source-part identifiers and no invented subcue times. Individual caption and part hashes, source SHA, original order and source times (or *null* for untimed) remain available.
- `review-queue.json`: every adjacent unverified P0 boundary and **each intra-caption dash or exact-contextual speaker-boundary hypothesis with its source Unicode offset**. On the two canonical pilots, it additionally includes **source-audio-informed P0 priority review** for 224 already-measured adjacent voice pairs, SHA-matched to the corresponding manuscript, original dialogue and film. Acoustic model disagreement points to useful re-listening, not verified turns or actor identities. The mandated P0→P5 priority order remains unchanged. All unresolved boundaries remain unresolved instead of being silently signed off.
- `manifest.json`: source version and SHA, exact saved file SHAs, script tier, counts, and acceptance/uncertainty flags.

**Fleet-wide P0 sentence continuity, source-only and free:** On timed subtitles, the factory now provisionally joins otherwise-unidentified adjacent cues when (a) the first ends with ellipsis and the second begins with a corresponding ellipsis, separated by at most 1.6 s, or (b) the first sentence is visibly unfinished and the next begins with a lowercase continuation within 0.9 s. **Any speaker dash in either cue vetoes this full-cue join**, even a single internal dash. Untimed transcripts, long gaps, known speaker disagreements and uncertain internal voice changes are left separate. In independent editorial reference comparisons, the narrowed patterns agreed on **34/34 source-adjacent S01E01 role continuations and 22/22 already context-named S05E05 continuations**. Those reference identities are themselves provisional and the sample does NOT establish whole-series accuracy: these are only reversible, **unverified** P0 hypotheses, never a claim that the audio was heard. For source-only episodes the result is longer, more readable unidentified-voice turns instead of one heading per subtitle. Every new grouping carries its source character spans, cue IDs, original timing, grammar basis and explicit pending P0 review record, with no role inferred.

**P0/P1 contradictory-role guard (all episodes):** The same narrow source-sentence continuity checks also run over *already named* cues, not just unidentified lines. When two neighboring captions appear to carry one unfinished sentence but their contextual character names disagree, the factory **does not overwrite either character, join the dialogue, or claim the soundtrack confirms the sentence**. Instead it records a high-priority `source_syntactic_role_conflict_focus` item with the original two cue IDs, proposed speaker names, sentence-continuity basis and original-A/V-unverified status, and counts it in the manifest. Source punctuation may itself be wrong, so this is a targeted review question, not an automatic attribution rule. An adversarial regression deliberately assigns the wrong character to the second half of a S01E02 sentence and verifies that the contradiction appears in P0/P1 review while the original caption text and times remain intact.

The script uses the *193 existing verified-index dialogue witnesses*. It never invokes a recognizer, sends transcripts to third parties, runs expensive model jobs or retrieves original video. SHA-256 guards refuse modified source files; bad/missing cue sequence, incorrect witness identity or invented untimed timestamps also fail. Repeated invocations are byte-for-byte idempotent: rerunning the same episode updates existing files only when the evidence or editorial manuscript has actually changed. A rerun never creates agent-vNN manuscripts.

## What the factory can and cannot do

**Pilots**: S01E01 has 404 original source units and 405 reading blocks; S09E19 has 347 original units and 323 reading blocks. Their current editorial readers provisionally name most source units, correctly distinguish the originally untimed S09 source, preserve available contextual splits and joins, and retain substantial source-linked dialogue and editorial material. The factory chooses these instead of discarding months of editorial work in favor of a generic subtitle renderer.

**Other 191 episodes**: the complete *available* subtitle source can be emitted immediately with cue-perfect reversible provenance. The second fully researched *text-only* episode is now **S01E02, “Santa Goes Downtown”**: its one source-locked 380-cue contextual ledger identifies **293 high/medium whole-cue speaker hypotheses**, proposes **72 exact-Unicode internal speaker switches with 144 labelled voice parts**, and abstains on **15** cues. Published role-labelled IMDb and Wikiquote excerpts seed specific high-confidence cases, and contextual continuity/references provide medium-confidence proposals. C349's Eddie→Santa speaker handoff is located by its single *second-voice dash*, which ordinary two-leading-dash detection misses. None is film-heard or certified; every cue, source word, and original SRT timestamp is unchanged. In addition to P0/P1 attribution, S01E02 now carries **64 selected P2 *textual delivery* proposals**, each with its own line-specific basis: teasing, sarcastic, exasperated, concerned, contrite, reassuring and other constrained labels. These appear as clearly labeled italic *textual hypotheses* in the screenplay, with exact source text preserved below, and as a separate `textual_delivery_p2_review` queue. They are **NOT descriptions of witnessed actor performance**: the factory refuses tones outside its limited vocabulary, fake original-soundtrack verification, and any proposed tone covering a multi-voice source cue. Only separately heard original film can certify performed delivery. This is a deliberately conservative LLM-friendly editorial aid, not an invented stage direction.

**S01E03, “The Former Harry Stone”:** An additional source-locked, full-episode dialogue-only editorial ledger now covers **385/385 original timed cues**, proposes **307 whole-cue character names**, **76 exactly located mixed-voice handoffs (152 named parts)** and retains **two deliberately unassigned cues**. Its **88 line-specific P2 textual delivery proposals** are annotated as editorial interpretation, not witnessed performance. Long-distance contextual correction: Harry's winning age-pool entry revealed at C383–C385 clarifies that he was the first voice in C67 and C68, Dan answered him, and Harry later apologized for crushing Dan's pen at C72. This also repairs a mistaken pair of same-speaker age guesses at C44–C45, Craven's departure C43 and Liz's prying concern C61; none substitutes contextual consistency for film hearing. The independent published S01E03 Wikiquote character labels specifically anchor Harry/Lana/groom/bride at C74–C77 and Dan/Harry at C221–C228 (the latter conversation is easy to misattribute by intuition). This is a *third* context-enhanced nonpilot episode, alongside S01E02 and S05E05, never audiovisual certification. The original source SRT SHA, cue characters and envelope times remain immutable.

**S01E04, “Welcome Back, Momma”:** The next 354-cue source-SHA-locked editorial pass identifies **301 high/medium whole-cue provisional characters**, **45 exact Unicode internal voice handoffs** (including four with just one internal source dash and one specifically identified punctuation-only question/answer switch), retains **8 honestly unidentified cues** and adds **86 source-dialogue-based textual P2 hypotheses**. Published character-labelled Wikiquote excerpts anchor Harry, Liz, Lana, Dan and Eleanor in two key courtroom passages; uncertain short office exchanges and unnamed pageant voices deliberately abstain. These are one-pass source-context interpretations, not original-AV-verified acting, picture or word corrections. Every original subtitle character and time is preserved.

**S01E05, “The Eye of the Beholder”:** Its **410 original SRT cues** now have **343 high/medium source-context whole-caption speaker hypotheses**, **52 exactly source-located within-cue two-voice changes**, **15 deliberate source-context abstentions**, and **232 individual P2 *textual* delivery suggestions**. The key speakers include Bull, Harry, Liz, Lana, Dan, Selma, blind defendant Ralph Foley and the film witnesses; the discrepancy between courtroom witness “Leonard Bloom” in dialogue and “Leonard Blum” in the guest credits is explicitly retained. Published attributed Wikiquote excerpts anchor selected courtroom exchanges. An important C93 conversation contains an unmarked within-caption Vincent→Iris handoff; this is editorial reasoning, not a performed boundary confirmed from soundtrack. The original SRT and original cue time envelopes remain exact. The 232 tone tags annotate what the text implies, never how the actors have been independently heard.

The factory automatically refreshes all five evidence-backed nonpilot episodes on its existing workflow when the ledgers change. Thus **186 episodes** remain source-only until further source-grounded editorial or audiovisual evidence is added. **Importantly, existing source-locked whole-episode editorial overlays are reused rather than discarded**: for S05E05 *Safe*, the already researched v2 textual pass supplies **265 high/medium single-cue provisional character hypotheses**, flags seven cues that contain proposed internal voice handoffs, and abstains on 27 unknown cues plus one low-confidence guess. All 300 original cue texts/times remain exact. The screenplay visibly labels every contextual speaker as *unverified*, keeps mixed-voice cues explicitly provisional instead of treating their labels as heard voices, carries the original evidence and alternatives into the P0/P1 review queue, and source-SHA validates the original overlay. A subsequent source-dialogue-only adjudication cautiously identified six additional S05E05 exchange voices, especially Christine's questions to the safe technician, Dave's countdown, and Roz's continuous complaint, each recorded with evidence and alternate plausible speakers; none is AV-verified. The S05E05 overlay also supplies seven editorially located, exact-character within-cue switches. These produce **14 separately labelled provisional voice parts** without deleting, rewriting or retiming any source character; all are marked unverified. Additional original-series episodes get the same enhancement automatically when whole-episode `derived/text-only-speaker-proposals-vN.json` editorial ledgers are committed for them.

 The machine cannot reliably derive who actually spoke every anonymous subtitle, when adjacent cues belong to one actor, actual scene changes, actors' comic delivery, costume and props or physical business just from caption text. In particular the `all` option does **not** claim 193 near-complete audiovisual screenplays. Actual source cut completeness is unknown and originally missed or inaccurate words cannot be detected without audio comparison. The built-in P0 pass renders distinct provisional voices when multiple caption lines carry speaker dashes, **or when one interior dash starts a second voice after undashed opening text**. It does not split a lone initial speaker dash, which has no second-speaker evidence. Source S01E01 cue C219 was already provisionally assigned to two different characters by the pilot's independent editor; the split is separately proposed by the single-interior-dash source-only rule. S01E02 cues C67 and C349 demonstrate the same structure, with C349's specific Eddie→Santa labels supplied by contextual editorial reasoning rather than punctuation alone. It conserves every original character in its provenance and keeps the source cue time envelope intact, without pretending the dash is a film-heard boundary or that unlocated contextual handoffs have exact word offsets.

**Pilot original-soundtrack P1 unknown voices:** The same two archived source-checked reports also tested **22 formerly unidentified original-film voice windows** (6 S01E01, 16 S09E19), none eligible for name promotion. The factory now copies only their exact source reading-block references, provisional *nearest* role, similarities and margin, and authentic original-video seek envelope into `original_audio_model_p1_unknown_voice_review`. **None are named in the screenplay**: model held-out accuracy fails acceptance (71.64% and 68.57%), and most nearest-role margins are tiny. For S09E19, the source transcript is genuinely untimed: a source-video listening seek hint is never presented as an invented subtitle timestamp. Every suggestion is pinned to the dialogue and film source SHA and remains a deferred listening question. Any forged verification, stale manuscript, or mismatched caption reference rejects the report.

**Pilot soundtrack triage:** The already-held original-film audio embedding comparisons supply 194 S01E01 and 30 S09E19 clean adjacent P0 comparisons. The factory links them only when both the original-source SHA and exact canonical screenplay SHA match and annotates suspect joins/splits in `original_audio_model_priority_p0`. Similarity cutoffs (≤0.55 for a displayed join and ≥0.80 for a displayed split) are only investigation-ordering heuristics, **not a calibrated probability of speaker identity or proof of a mistake**. A changed manuscript makes the old report stale and un-applied. No media/PCM/embedding vectors leave the original source workflow; these are already preserved numerical reports, so one-click generation does not download or analyse film again.

For near-complete **performed** scripts, the still-required product lane is the existing [one-pass source-AV finisher](ONE-PASS-EPISODE-FINISH.md): continuous original-film review, full P0 turn and P1 voice confirmation, P2–P4 observations, with the single stable decision ledger and independent QA. The source-audio role model has shown only ~69–72% provisional-role holdout accuracy on the two pilots, so auto-accepting its guesses would degrade the final product. This factory intentionally refuses to label such machine proposals as witnessed truth.

## Acceptance and operations

Run `PYTHONPATH='Night Court/tools' python -m unittest -v test_script_factory test_episode_finish` to verify the two canonical scripts, 193 indexed episodes, exact cue preservation, original witness hashing, idempotence and lack of fabricated AV approvals. CI runs those tests automatically on factory PRs and before every manual publication. If `main` advances during the write, the fast-forward commit fails safely rather than overwriting another editor.

The output is private because the original dialogue corpus is held for owner-authorized research. Never expose the artifacts publicly, including Actions logs. Original media is never embedded in an artifact. If the factory produces a source-only script, assigning fresh characters by intuition is editorial work requiring a source-bound amendment; claiming the audio or video was witnessed requires the original-source acceptance record.

**Original-film picture/physical-comedy model evidence (pilot microbenchmark):** The existing owner-only Qwen video pipeline can now run after the repo move. On October 28 it successfully processed one checksum-verified **2-second** silent original-AVI excerpt from each pilot, returning unverified ten-field visible-action/prop hypotheses. CPU inference took **68.249 s** for S01E01 and **38.144 s** for S09E19, plus model load; this is too slow for dense 20-minute episode coverage without substantial acceleration. The source-picture workflow persists only bounded model JSON, deferred review questions and SHA-linked metrics at stable private paths. The one-click factory exposes those as `original_film_visual_model_only_review` (P3 props and P4 actions) while **never injecting model descriptions into the screenplay** or declaring scenes/performance accepted. The trusted owner visual publisher also regenerates and saves both canonical pilot factory packages in **the same atomic private commit** as the original-picture model reports. GitHub's built-in Actions-token commits do not start a separate push workflow, so we do not rely on that for picture-evidence refresh. A guarded source-output rebase tolerates unrelated concurrent main changes but never overwrites the 14 exact protected evidence and factory files. Subsequent model tests update the same stable paths. Every source clip is verified against the original film SHA and only an actual source-picture review may authorize verified stage directions. This is one additional useful piece of evidence, not an episode completion claim.

**Two levels of completion must remain distinct:** (1) complete *available source dialogue* delivered and retrievable; (2) complete, verified performed AV screenplay. This workflow automates the former and reuses the best existing validated evidence for the latter. It does not falsely report level (2).
