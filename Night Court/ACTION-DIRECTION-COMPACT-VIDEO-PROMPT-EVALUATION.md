# Opt-in concise action-direction visual-model prompt benchmark

**October 25, 2026. Status: source-free implementation, NOT yet measured using original episode footage with this prompt.** The original 10-field `standard` prompt remains unchanged and default. This adds a distinct `action_compact` prompt profile for **controlled comparison**, not automatic production promotion. It responds to two original-source [physical-business Qwen runs](ORIGINAL-QWEN-PHYSICAL-BUSINESS-RESULTS-2026-10-25.md): the structured-JSON-valid S01E01 machine text reversed which person performed the touch, and the S09E19 original Qwen text failed its ten-field parser after about 164 seconds inference. A valid JSON format is not evidence of correct action agency, and the exact cause of S09's unparseable response is unproven.

`action_compact` still requires the **same exact ten top-level string keys** in the established schema, but asks for **short visible-only field phrases** (at most eight words per string), anonymous actors and explicit **actor→gesture→recipient** directional assignment. It bars extra prose, plot motive and guessed props. The aim is fewer tokens spent on uncheckable atmosphere and more discriminative visual facts within the hard model output budget. This text is untested as a real vision accuracy improvement, and its strictness could potentially reduce observed event recall. **Never claim otherwise before paired original-video human validation.**

The API and CLI use `--prompt-profile standard|action_compact`, with `standard` the fully backwards-compatible default, while every result persists **both the profile name and SHA-256 of the exact prompt bytes**. Only these two fixed profiles are recognized. No user-supplied arbitrary text is accepted as an inference prompt, no model weights or source files are downloaded by tests, and no original film content enters ordinary PR CI.

Source-free QA compares identical synthetic source SHA and exact clip windows using the fake local model for each fixed profile, verifies their distinct prompt hashes, and asserts both reports remain machine-proposed rather than source accepted. This tests contracts and provenance **only**, not Qwen's actual text compliance.

To evaluate **only if justified** after original film reviewer coverage is available, run standard and compact against the **same exact short original-source window**, using the same pinned model revision, FPS/width/token limit and rights/privacy-approved trusted source environment. If needed, use the existing safe generated-video smoke first. Compare: (a) ten-field JSON validity, (b) separately reviewed who-did-what-to-whom direction, (c) missing props/physical comedy and speculative interpretation, (d) inference/tool/reviewer time per accepted visual stage note. Use [independently labeled event truth](VISUAL-MODEL-QUALITY-SCORECARD.md) and [editorial yield](VISUAL-REVIEW-YIELD-SCORECARD.md) only after actual original moving film, **not** after still inspection.

Do not launch series-wide CPU inference because a prompt is more compact. Two original 2-second CPU clips cost roughly three minutes each before CI/bootstrap; any prompt or frame-rate change must prove useful screenplay output or material cost savings. Original dialogue, screenplay acceptance and 0/193 complete independent audiovisual episode certifications remain unchanged.
