# Source-fingerprinted, candidate-shot-bounded continuous action review

**State: software implemented; synthetic review-selection tests required; semantic original-video calibration pending.** No video, stage directions, speaker identification or official shot-cut labels are generated by the planning step.

## Why this stage exists

The successful S09E19 original AVI source pass [#40128021777](https://github.com/gamesbyian/general-purpose/actions/runs/40128021777) measured **0.053 seconds** to score 31 triple-image samples, but those grayscale features cannot distinguish an actor's gesture from camera motion, laughter, noise, illumination or missed image edits. The next step must examine *short continuous original AVI passages*, not create action descriptions from the scores.

`tools/plan_continuous_action_review.py` consumes three already measured inputs from **the same SHA-verified original video edition**:

1. The candidate-cut-safe original native-fps video frame sampling plan.
2. The original-PTS-and-frame-SHA-verified ephemeral triad pixel-change metadata.
3. The ordered FFmpeg full-video **image-change candidates**, not independently established shot boundaries.

The algorithm retains source confidence boundaries and builds at most **12 requested clips** of approximately 0.5–2.8 seconds each, using a 1,200ms context halo around each selected triad (trimmed by a conservative 150ms candidate-cut margin). It rejects forged source hash, candidate cut counts, duplicate/invalid cuts, cross-partition **actual** source PTS and invalid triad ordering. Too-short intervals are explicitly deferred rather than interpreted.

### Balance and bias checks

Reserve up to **six** high-priority original editorial action review events first. Then reserve up to **four** other high-score triads for efficient discovery. Finally include **two** lowest-score remaining **control windows** to estimate missed physical comedy and false assurance caused by a pixel-score threshold. Free places may be allocated to remaining source coverage probes. No video excerpts are decoded or retained here: the output is only a short executable-review manifest, paired with original source timestamps, candidate cut partition and SHA.

Each request carries a boolean false gate for original human cut/gesture review, actual continuous-video interpretation, voice verification and draft stage-direction acceptance. The original S09E19 transcript's 347 paragraphs remain null-timed. No p95 episode runtime or accuracy change is claimed from these offline selection tests.
