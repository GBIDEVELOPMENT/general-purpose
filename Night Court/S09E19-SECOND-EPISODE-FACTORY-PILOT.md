# S09E19 second original-series source-once audiovisual throughput pilot

**State:** Implementation and synthetic/offline verification proposed. Actual second original source run pending until PR merges. The first S01E01 exact-original integrated source-once run [#40115701804](https://github.com/gamesbyian/general-purpose/actions/runs/40115701804) completed two genuinely distinct free-decoding ASR systems, full-video image-change scan and up to 240 selected JPEGs in **239.826 seconds**, excluding job installation. That is an encouraging single-case speed result, not p95 for 193 original-series episodes.

This second pilot intentionally tests a different episode and source-witness format. **S09E19** has 347 original **untimed** subtitle-source paragraphs (SHA `659beb9c50fabdd1028aac9570999d9a16b36e6d582938e10809cc0c664530b2`), not an original SRT. Six existing original-source 15:00–15:25 sampled visual tasks are already pending. The accepted owner file inventory locates exactly one candidate `Night Court - 9x19 - P.S. Do I Know You.avi`, **183,377,920 bytes**, original AVI SHA-256 `51f409c620245f9f3744b1b38e534122fd8c82cfadc2221bf5f6fc14eac93649` previously verified by bounded source pilots.

The new `tools/profile_s09e19_source_once_factory.py` reuses the existing production-tested S01E01 primitives, **without an entirely new model or video processing stack**. It downloads the source once, checks AVI SHA and size, decodes exactly one original mono PCM, freely decodes with **Whisper tiny.en** and a separate **Vosk/Kaldi HMM WFST** recognizer without original text prompts, and measures their independent agreement. It scans all decoded video frames at 160px for contrast-change candidate timestamps, then source-PTS-checks at most 240 ephemeral JPEGs, prioritized to six real sampled visual research tasks and up to 26 uniformly spaced coverage probes.

This test also consults the exact **347 untimed original paragraphs** in a separate inexpensive lexical pass on **at most 40** evenly selected machine-agreed dialogue spans. Model inference timestamps are **original-video AUDIO hypotheses only**. In every source-paragraph match, **original_source_paragraph_time_ms remains null**. No fictional dialogue timestamp, human source listening, character identity, vocal delivery, editing truth or AV-complete screenplay gets promoted. Frames and original sound/model weights remain in one temporary runner directory, and the sole exported result is a compact JSON with source/media hashes, per-stage wall times, candidate counts and bounded text hypotheses.

## How this will be run

1. Prove synthetic original-series hashes, 347 true untimed source paragraphs, the six existing original-video task constraints, absence of invented subtitle times and ≤240 frame output through no-secret CI.
2. Merge the reviewed source worker and owner-only `.github/workflows/night-court-trusted-s09e19-source-once.yml`.
3. Open a one-shot PR from `research/night-court-s09e19-source-once-trigger`, adding only `Night Court/research/trigger-s09e19-source-once-fast.txt`. The workflow checks out the **trusted base SHA**, not PR-head code, and uses the existing FTP secret only for original media access. The source trigger PR is closed without merge after completion.
4. Preserve exact original result metadata, compare measured actual full-episode wall time against the 239.826-second S01E01 baseline and prepare a focused review queue for uniquely matched untimed paragraphs, without altering the 347 originals.
5. The initial <=30-minute p95 target remains unproven across 193 episodes; two pilot points should not be advertised as population p95. Vision-language content understanding and detailed acting annotation remain unmeasured downstream work.

**Goal:** demonstrate fast processing is robust even without pre-timed dialogue sources. Stay source-faithful, don't repeatedly download videos or run several redundant recognition passes, and measure costs before broad rollout.
