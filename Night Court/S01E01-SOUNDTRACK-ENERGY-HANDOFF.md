# S01E01 original-video mixed-soundtrack 100ms audio level pilot

The first S01E01 script scene spans 11 typographic original SRT speech turns and six preliminary stage actions. The original 01:00–01:30 mixed sound analysis failed to cover full C19 (starting 00:58.912) and C27 (ending 01:31.074). The [36.162s source review cut](S01E01-REVIEW-CUT-HANDOFF.md) now provides a SHA-verified 00:56.912–01:33.074 audiovisual scope.

`tools/probe_s01e01_audio_energy_envelope.py` uses the exact original-AVI SHA and size, exact SRT SHA and the existing 17-task immutable review manifest. It decodes **36.162 seconds of mono 16kHz original television mix to ephemeral memory only**, computes 100ms RMS/peak dBFS metrics and reports a source-time-indexed **energy envelope** and per-11-caption-turn summary statistics. Original AVI and transient PCM are discarded automatically; all committed/artifact evidence contains only numeric JSON. Synthetic tests use generated 440Hz sound and a known 2-second silent interval, no original TV media.

The energy envelope is an **original television mixture measurement**. Audible crowd laughter, soundtrack music, sound effects, silence, movement and overlapping dialogue all contribute. It **cannot verify any source caption words, source-to-video synchrony, voice identity, separate acting emotion or an actor's actual vocal range**. Source time bins are nominal extraction positions, not independently accepted word alignments. Near the C19 and C27 original excerpt boundaries, level changes can flag where a human listener should inspect an original AVI, but can never certify the source caption.
