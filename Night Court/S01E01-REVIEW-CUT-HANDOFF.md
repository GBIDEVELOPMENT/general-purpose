# S01E01 continuous original-source editorial review cut

The first scene's original **01:00–01:30** sample does not actually include the entire source-cue time range of the 11 caption turns. C19 starts at **00:58.912** and C27 ends at **01:31.074**. To avoid certifying an incomplete turn and make the 17-task review operational, `tools/build_s01e01_review_cut_manifest.py` builds one bounded, padded and source-fingerprinted **00:56.912–01:33.074** original-video cut list. This 36.162-second window covers all 11 original caption turns and six observed visual-action intervals, including a 2-second lead-in/trail-out and the sampled telephone-receiver action. It does **not** verify the actual subtitle synchronization or that every line is complete.

The versioned [review-cut metadata](seasons/S01/S01E01/derived/editorial-review-v1/review-cut-manifest.json) preserves the original AVI/SRT SHA-256s, expected original owner-held AVI byte length, original legacy filename *candidate*, every source task ID, exact source intervals, the old pilot bounds and explicit out-of-sample tasks. The video filename is a **candidate only**, not an audiovisual source proof. The tool requires agreement with the existing source-hash-linked integrated scene and 193-episode AV queue, and refuses prior acceptance claims or missing tasks. PR CI independently rebuilds and compares the versioned manifest.

## Private reviewer use

Run `python 'Night Court/tools/build_s01e01_review_cut_manifest.py' --source-video /path/to/verified-original.avi --render-to /private/outside/repository` from the repository checkout with FFmpeg available. Rendering is optional, local only, and refuses any source AVI whose exact byte length or SHA-256 disagrees with the established original source. It writes short MP4 review excerpts **only outside the Git checkout**; it neither contacts FTP nor uploads any audio, source video, thumbnails, biometric features or model artifacts. The generated media must not be committed or redistributed.

A reviewer must listen to the original voice turns (C19, C22 and its potentially multiple voices, C24 and C27 especially), check actual word fidelity/time margins, inspect uninterrupted frame/action coverage around OBS-V2-01…06, and only then complete evidence-linked decision records according to `S01E01-EDITORIAL-REVIEW-HANDOFF.md`. A cut-list producer cannot count as a human listener, confirm emotion or character identity, independently accept a physical action or certify episode completion. The acceptance baseline remains **0/17 tasks and 0/193 full scripts**.

The 36.162-second video edit is a **review convenience**, not a reconstructed scene or an independently verified source transcript edition. For real review use the unmodified original AVI as authoritative source, not a transcoded excerpt when assessing fine synchronization, sound or image artifacts.
