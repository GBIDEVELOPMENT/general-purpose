# Original design reference images

These are the original uploaded raster reference files, moved without resampling or recompression from the PocketBoard project root.

- `reference-controls-palette.jpg`: the labeled UI control and palette sheet (some elements are painted over in the source).
- `reference-play-button.png`: separate large Play symbol reference.
- `original-launcher-upload-01.png` and `original-launcher-upload-02.png`: original uploaded launcher raster references, retained verbatim. Their original opaque filenames were intentionally replaced with stable inventory labels; the precise source roles were not independently certified in this cleanup.

Canonical editable traces live in `../button-symbols/`, `../button-silhouettes/`, and `../launcher/`. Runtime assets must be generated from those traces, not re-traced from screenshots on each revision.
