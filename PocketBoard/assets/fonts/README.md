# PocketBoard fonts

Slabthing is the canonical default font for all PocketBoard UI text. The owner-supplied source font is `PocketBoard/Slabthing-YvLL.ttf`. The Android copy at `android/app/src/main/res/font/slabthing.ttf` and the archived copy at `assets/fonts/Slabthing.ttf` are byte-identical to that TTF source.

The earlier `slabthing-font.zip` remains in the project for provenance, but is not used for app builds. Morning Rainbow is retained as a historical font asset, not the default. Verify font licensing before redistribution outside the project.
